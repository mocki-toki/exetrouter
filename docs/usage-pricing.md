# Usage: estimated API price

The Usage dashboard offers **USD estimate** next to Tokens and Requests. It calculates an OpenAI **standard API equivalent**, not actual ChatGPT subscription spending, invoices or the monetary value of reset credits. These routes use ChatGPT Codex OAuth rather than a billable Platform API key. The price table is sourced from [OpenAI API pricing](https://developers.openai.com/api/docs/pricing?latest-pricing=standard), checked November 12, 2026; it is fixed in the server release and is not a historical pricing ledger. It does not apply regional, batch, Fast or promotional adjustments. Earlier usage therefore also uses this release's rates, not prices as of the request date.

For each request with a supported text model and known input, cached-input and output counters, the estimate is `(input - cached) × input_rate + cached × cached_rate + output × output_rate`, divided by 1,000,000. The published long-context rates apply when the **request input** exceeds 272,000 tokens; otherwise short-context rates apply. Summation happens per request **before grouping**, so mixed Astra/Sol groups are weighted by their respective prices. Unknown counters or unpriced models (including image requests whose text/image token split is unavailable) are omitted and counted as `unpriced_requests`; the cost remains null when no requests can be priced. A partial estimate must not be presented as a complete total. The actual provider may apply other pricing terms or not charge per token at all.
